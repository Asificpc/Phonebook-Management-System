# C Phonebook Management System

A console-based Phonebook Management System developed in C.

## Features

- Add new contacts
- Search contacts by name or mobile number
- Modify contact information
- Delete contacts
- List contacts alphabetically
- Mark contacts as favorites
- View favorite contacts
- Unmark favorite contacts
- Undo the last action
- Store contacts using file handling

## Technologies Used

- C Programming Language
- File Handling
- Structures
- Functions
- Arrays

## How to Run

Compile the `phonebook.c` file using a C compiler and run the generated executable.
